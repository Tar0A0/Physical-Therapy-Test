# 專技高考物理治療師國考隨機抽題測驗系統

收錄 **108 年第一次～115 年第二次**專技高考物理治療師考試共 **16 次考試、6 大科目、7,680 題**歷屆考畢試題與更正答案，搭配 **30,720 條離線繁體中文逐選項詳解**，支援手機桌面安裝與離線刷題（PWA）。

---

## 功能特色

- **彈性篩選與防重複抽題**
  - 可依「年分」與「科目」自由篩選或全範圍混合抽題，並支援選項隨機打亂。
  - 自動綁定「承上題／呈上題／同上題／依上題」題組一起抽出，維持前題脈絡。
  - 內建「同份考卷／範圍抽完前不重複」、1 小時～30 天或自訂時效防重複，以及單一範圍已抽紀錄重置。
- **考卷式作答體驗**
  - **可跳題空白交卷**：未作答題目交卷前會於頁面內提示「還有 N 題未作答」，可一鍵跳至漏答題或直接交卷（未作答一律計為答錯）。
  - **作答進度與題號跳題列**：畫面上方固定顯示目前作答進度（如 `12 / 50`）與「跳至未作答」按鈕，題號列表預設收合以節省手機螢幕空間，需要時可展開直接跳題。
  - **非阻斷式頁面提示**：所有提醒與確認皆改以頁面內紙本風格橫幅呈現，不跳出原生 `alert`／`confirm` 視窗打斷作答。
- **逐選項詳解、錯題簿與弱科統計**
  - **離線逐選項解析**：交卷後同時顯示正解與各誘答選項解析，並提供「問問 Gemini（自動帶入詢問）」與「Gemini App（複製貼上）」按鈕進一步延伸學習。
  - **錯題簿**：答錯或未作答題目自動收錄（可開啟「答對自動移出」），支援針對錯題再測驗。
  - **各科正確率統計與近期趨勢**：跨次永久累計各科正確率（不受最近 20 筆明細上限影響），依正確率由低到高排序並標示 60% 及格線與「弱科」徽章，搭配近期趨勢長條圖一眼找出弱科。
- **極速按需載入與 PWA 離線刷題**
  - 題庫依「年度／科目」拆分為 96 個 gzip 壓縮分塊（`data/chunks/*.json.gz`），首頁開啟僅載入約 5.5 KB 的 `data/manifest.json`，選定範圍與題數後才下載對應分塊並於瀏覽器原生解壓。
  - 支援安裝至手機桌面（Android Chrome／iOS Safari 加入主畫面），並提供「離線下載全題庫」按鈕（一次快取全部 96 個分塊約 2.4 MB），通勤無網路也能完整刷題。
- **自訂題庫與考選部同步**
  - 支援匯入自訂 CSV 題庫（提供 `template.csv` 範本）及透過 `sync-moex.js` 自動抓取考選部考畢試題平臺與 OpenData 最新年度試題、答案與更正答案。

## 快速開始

### 1. 本機啟動伺服器（推薦）

由於瀏覽器在 `file://` 本機路徑下會限制 `fetch` 與 Service Worker，本機使用請透過內建 Node.js 伺服器開啟：

```powershell
node sync-moex.js --serve
```

啟動後於瀏覽器開啟：`http://127.0.0.1:3000/`（可加 `--port 8080` 指定連接埠）。

### 2. 安裝為手機 App 與離線使用（PWA）

1. 透過 HTTPS（例如 GitHub Pages）或本機 `http://127.0.0.1:3000/` 開啟網頁。
2. 點選題庫列的 **「離線下載全題庫」**，即可將全部 96 個題庫分塊（約 2.4 MB）快取至裝置中。
3. 點選 **「安裝至主畫面」**（或於 iOS Safari 使用「分享 → 加入主畫面」），即可像原生 App 一樣從桌面開啟並在無網路環境下刷題。

## 題庫同步與建置指令

當考選部公告新年度試題或更新 `option-explains.json` 後，可使用下列指令同步與重建分塊題庫：

```powershell
# 依考選部網址、考試代碼或年度抓取「專技高考_物理治療師」試題／答案／更正答案並重建題庫
node sync-moex.js "https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx?y=2025&e=114090"
node sync-moex.js --year 114
node sync-moex.js --opendata

# 僅重新解析本地 題庫/ PDF、合併 option-explains.json 與 TABLE_OVERRIDES
node build-bank.js
```

## 專案檔案結構

| 檔案／目錄 | 說明 |
| --- | --- |
| `index.html` | 測驗設定、作答表單、成績統計與頁面內提示架構 |
| `app.js` | 分塊按需載入、gzip 解壓、題組抽題、作答進度與跳題、批改詳解、錯題簿、各科統計與 PWA 離線快取 |
| `style.css` | 試卷紙本風格樣式與手機版響應式排版 |
| `manifest.webmanifest` | PWA 設定檔（支援獨立視窗模式與桌面安裝） |
| `sw.js` | Service Worker（App Shell 與題庫分塊／圖片離線快取） |
| `icons/` | PWA 應用程式圖示（`icon.svg`、`icon-192.png`、`icon-512.png`） |
| `data/manifest.json` | 題庫索引檔（年度、科目、題號與分塊檔案清單） |
| `data/chunks/*.json.gz` | 按「年度／科目」拆分的 96 個 gzip 壓縮題庫分塊 |
| `option-explains.json` | 全題庫 7,680 題 × 4 選項（30,720 條）繁體中文離線詳解來源 |
| `img/` | 題目與選項附圖（已完成水平拼接與深灰邊框裁切） |
| `題庫/` | 考選部歷屆考畢試題、答案與更正答案原始 PDF 與索引 |
| `build-bank.js` | 解析 PDF、合併詳解與表格覆寫並生成 `data/manifest.json` 與 gzip 分塊 |
| `sync-moex.js` | 串聯考選部考畢試題平臺與 OpenData CSV 並提供本機同步伺服器 |
| `template.csv` | 自訂匯入題庫 CSV 範本 |
| `DEVELOPMENT_RULES.md` | 詳解格式規範、開發禁止事項、圖片／表格處理標準與維護避坑紀錄 |
