# 物理治療師國考題庫練習系統 — 專案規範與避坑紀錄

本文件記錄本專案開發與維護過程中**必須避免的問題（避免的東西）**與**已確立的標準架構（固定的東西）**，供後續更新題庫或調整前端功能時依循。

---

## 一、避免的東西（禁止事項與已排除的踩坑問題）

### 1. 不串接外部 AI API／不要求使用者輸入 API Key
- **禁止**在前端（`index.html`、`app.js`）要求使用者填寫 API Key 或即時呼叫 Vertex AI / Google AI Studio API。
- **原因**：使用者申請金鑰常遇到金鑰前綴差異（`AQ...` 與 `AIza...`）、GCP 專案未啟用 `aiplatform.googleapis.com`、或 IAM 缺少 `aiplatform.endpoints.predict` 權限等問題，導致測驗途中解析失敗。
- **替代作法**：全面改為離線內建逐選項詳解（見下方「固定的東西」）。

### 2. 避免圖片被水平分割或殘留深灰黑框
- **禁止水平分割呈現**：部分考選部 PDF（例如 115 年第一次、第二次）將單張附圖拆成多段水平條狀 XObject；嚴禁讓同一張圖片以多組 `[IMG:...]` 換行標籤分別渲染，否則畫面會產生斷裂、圓角切塊與上下空白間隙。
- **禁止殘留深灰陰影邊框**：部分圖片轉檔後四邊帶有深灰色背景與陰影（`rgb(22..42)`）；嚴禁未裁邊就直接拼接或顯示，必須先裁除四邊深灰邊框，並將混合縮放比例的條帶對齊寬度後，垂直無縫合併成單一張完整 PNG。

### 3. 避免 PDF 向量表格文字黏連、遺失格線
- **禁止**直接輸出 PDF 原始萃取出的黏連表格文字（例如 `<153153-170171-191>191`、`4555 65 75`）。
- **原因**：考選部試題 PDF 常以向量線段繪製表格框線，純文字擷取只會抓到沒有邊界分隔的文字。必須補回結構化表格語法並以格線表格呈現。

### 4. 避免採用未更正的原始答案
- **禁止**在考選部已公告「更正答案（MOD）」的情況下仍使用原始「答案」PDF 作為唯一標準答案，亦不可忽略「一律給分」或「多選均給分」規則。

### 5. 避免重建題庫時覆寫已修復的圖檔
- **禁止**在 `build-bank.js` 執行時無條件以 PDF 原始碎片覆寫 `img/` 資料夾內已經去框或拼接完成的 PNG 檔案（`extractImages()` 必須先檢查目標檔案是否已存在）。

## 二、固定的東西（專案固定規範與標準架構）

### 1. 題庫範圍與標準答案規範
- **題庫規模**：收錄 114 年第一次、114 年第二次、115 年第一次、115 年第二次專技高考物理治療師考試共 6 大科目、合計 **1,920 題**。
- **答案優先序**：`build-bank.js` 優先讀取「更正答案」PDF；若無更正檔案才讀取「答案」PDF。
- **多解與送分格式**：支援 `answers` 陣列儲存多個正確選項索引（包含全對一律給分），並於 `explain` 欄位固定註明考選部更正說明。

### 2. 離線逐選項詳解（`optionExplains`）
- 全題庫 1,920 題、每題 4 個選項（共 **7,680 條**）皆配備繁體中文選項解析。
- 詳解資料集中維護於 `option-explains.json`（鍵值格式為 `${exam}||${subject}||${num}`），再由 `build-bank.js` 彙整寫入 `questions.js`。

### 3. 交卷後顯示與測驗介面行為
- **作答期隱藏解析**：作答過程中不顯示任何對錯提示或選項詳解。
- **交卷後統一揭露**：按下「交卷」後，於每個選項下方顯示 `.opt-note` 區塊與標籤（`✔ 正解選項` 或 `✘ 選項解析`）及對應詳解；題目下方顯示整體對錯、更正備註與出處（`考試別・科目・第 N 題`），並記錄成績至瀏覽器 `localStorage`。
- **使用者舊資料提醒**：若使用者曾匯入自訂 CSV 題庫於 `localStorage`，點選「恢復預設題庫」即可重新載入內建 `questions.js`。

### 4. 圖片與表格固定處理機制
- **圖片標籤與合併**：
  - `build-bank.js` 透過 `collapseImgStrips()` 將題幹或單一選項內連續的 `[IMG:...]` 合併為首張 `[IMG:檔名.png]`（對應 `img/` 中已完成拼接與去框的單一完整 PNG）。
  - `app.js` 的 `fmt()` 同樣保留連續 `[IMG:...]` 合併處理作為防護，再轉為 `<img class="q-img">` 或 `<img class="q-img-inline">`。
- **表格語法與樣式**：
  - 向量表格題固定在 `build-bank.js` 的 `TABLE_OVERRIDES` 中以 Markdown 管線表格格式（`| 欄1 | 欄2 |`）維護（例如 `114年第一次 神經疾病物理治療學 Q12`、`115年第一次 神經疾病物理治療學 Q77`）。
  - `app.js` 的 `fmt()` 自動將管線表格區塊轉為 `<table class="q-table"><tbody>...</tbody></table>`，並套用 `style.css` 的 `.q-table` 實線邊框樣式渲染。

### 5. 題組綁定與隨機抽題
- 題幹包含 `承上題`、`呈上題`、`同上題`、`依上題` 且同考試別與同科目者，在 `app.js` 的 `start()` 中固定綁定為同一題組一併抽取，避免題目失去前題情境。

## 三、主要檔案與標準建置流程

| 檔案 | 固定職責 |
| --- | --- |
| `index.html` | 測驗設定、題目顯示與成績結果頁面結構（無任何 AI Key 輸入欄位） |
| `app.js` | 題庫載入、CSV 匯入、題組抽題、`fmt()` 表格與圖片渲染、交卷批改與逐選項詳解顯示 |
| `style.css` | 題目卡片、表格（`.q-table`）、圖片（`.q-img`）、對錯選項與詳解區塊（`.opt-note`）樣式 |
| `option-explains.json` | 全題庫 1,920 題 × 4 選項之繁體中文離線詳解來源檔 |
| `build-bank.js` | 解析考選部試題與更正答案 PDF、合併 `TABLE_OVERRIDES` 與 `option-explains.json`、生成 `questions.js` |
| `questions.js` | 網頁實際載入的完整題庫資料（`window.QUESTIONS`） |
| `img/` | 題目與選項附圖（已完成水平條帶拼接與深灰黑框裁切） |

### 重建題庫標準指令
更新 `option-explains.json`、`TABLE_OVERRIDES` 或 PDF 題庫後，執行：
```powershell
node build-bank.js
```
執行後會自動保留 `img/` 中已處理完成的圖片，並重新輸出完整的 `questions.js`。
